# GDG Gurugram University

Full-stack community platform for Google Developer Group at Gurugram University.

## 🚀 Quick Start

### Start Everything (Recommended)
```bash
./start-all.sh
```

This will start:
- PostgreSQL (port 5432)
- Backend API (port 3001)
- Frontend (port 3000)

### Stop Everything
```bash
./stop-all.sh
```

## 📱 Access

- **Frontend**: http://localhost:3000
- **Backend API**: http://localhost:3001
- **API Health**: http://localhost:3001/api/health

## 🛠️ Tech Stack

**Frontend**: React + TypeScript + Tailwind CSS + Vite  
**Backend**: Spring Boot + PostgreSQL + JPA  
**Tools**: pnpm, Maven, Docker

## 🎨 Features

- ✨ Beautiful light mode design with frosted glass effects
- 📱 macOS-style mobile dock navigation
- 🎯 Smooth scrolling with Lenis
- 🔄 Full backend integration
- 🎭 Animated UI elements
- 📊 Event, News, and Team management

## 📝 Notes

- Backend runs on port 3001
- Frontend runs on port 3000
- PostgreSQL runs in Docker
